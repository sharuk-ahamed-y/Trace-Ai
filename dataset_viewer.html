🚀 Streamlit Interactive Viewer

To launch the interactive Streamlit dataset browser with live gallery filters, graph rendering, side-by-side pair comparison, and CSV search tables, run:

And open http://localhost:8501 in your browser.

📁 Benchmark Files Layout

  • image_provenance_dataset/images/ — Train, Validation, and Test image folders split by source identity
  • image_provenance_dataset/metadata/ — images.csv, pairs_*.csv, edges_*.csv, graphs_*.json
  • image_provenance_dataset/features/ — forensic_features.csv and raw *.npy feature vectors
  • image_provenance_dataset/graphs/ — Individual graph JSON ground truth files for all 100 provenance trees
  • image_provenance_dataset/visualizations/ — PNG graph tree diagrams
